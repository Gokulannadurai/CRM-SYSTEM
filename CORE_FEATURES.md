### Backend Implementation

#### Technology Stack
- **Java 21**: Latest LTS version
- **Spring Boot 3.x**: Rapid application development
- **Spring Security**: Security framework with JWT
- **Spring Data JPA**: Data access layer
- **PostgreSQL 15**: Robust relational database
- **Flyway**: Database migration tool
- **Maven**: Build and dependency management

#### Microservices Architecture
- **Auth Service** (Port 8080): Authentication and authorization
- **User Service** (Port 8081): User management and administration

- **Sales Service** (Port 8083): Lead, task, and sales pipeline management
