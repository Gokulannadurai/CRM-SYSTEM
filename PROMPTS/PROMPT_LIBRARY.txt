================================================================================

1. PROJECT REQUIREMENTS DOCUMENT (PRD) GENERATION:
   ```
   Act as a Senior Technical Architect and generate a comprehensive, production-grade 
   Product Requirements Document (PRD) named project.md in Markdown format.
   
   The document should cover all critical technical and business aspects. Use your 
   expertise to infer missing pieces, recommend best practices, and structure everything 
   clearly for stakeholders including engineers, product managers, and QA.
   
   Structure of the PRD (project.md):
   - Project Overview
   - Business Goals and Objectives
   - Stakeholders
   - Target Users
   - Functional Requirements (written as user stories with acceptance criteria)
   - Non-Functional Requirements (performance, scalability, availability, security and maintainability)
   - Technology Stack Recommendations
   - Success Metrics and KPIs
   - Risk Assessment and Mitigation
   - Timeline and Milestones
   ```

2. ARCHITECTURE DESIGN GENERATION:
   ```
   Based on the PRD, create a comprehensive system architecture design document

   - Component Layout (Frontend, Backend, Services, Database)
   - Technology Stack Selection
   - Security Architecture
   - Scalability and Performance Considerations
   - Deployment Architecture
   - Integration Patterns
   - Data Flow Diagrams
   - API Gateway Design (if applicable)
   - Monitoring and Logging Architecture
   ```

   ```
   Create a comprehensive database design document named DATABASE_DESIGN.md.
   ```
